## 📚 Projects & Assignments

### 1. Homework 2 – Machine Learning Fundamentals

**Notebook:** `Homeword2.ipynb`

This assignment focuses on applying machine learning algorithms to practical classification problems.

**Topics covered:**
- Data loading and preprocessing using Pandas.
- Perceptron classification algorithm.
- Confusion Matrix and model evaluation.
- Customer loan status prediction.
- Investigation dataset analysis.
- Spam and NoSpam message classification.
- Text feature extraction using CountVectorizer.

**Datasets:**
- `Investigation_dataset.csv`
- `Bank_dataset.csv`
- `SpamMessageDetection.csv`

### 2. Homework 3 – Python, NumPy & Data Analysis

**Notebook:** `Homework3.ipynb`

This assignment explores Python programming, numerical computing, and exploratory data analysis.

**Topics covered:**
- NumPy arrays and matrix operations.
- Array indexing, slicing, and filtering.
- Statistical calculations using NumPy.
- Data manipulation with Pandas.
- Exploratory Data Analysis (EDA).
- Descriptive statistics.
- Data visualization using Matplotlib.
- Boxplots and histograms.
- Perceptron learning and bias terms.

**Datasets:**
- `WestRoxbury.csv`
- `perceptron_toy_dataset.csv`

### 3. Homework 4 – Data Science & Deep Learning

**Notebook:** `Homework4.ipynb`

This assignment focuses on image processing, feature extraction, machine learning, and deep learning applications.

**Topics covered:**

**Image Processing & Feature Extraction**
- Image loading and preprocessing.
- Image resizing and segmentation.
- Roundness and Elongation feature extraction.
- RGB color feature analysis.

**Machine Learning**
- Logistic Regression.
- One-vs-Rest classification.
- StandardScaler normalization.
- Apple, Banana, and Orange classification.
- Model evaluation using Accuracy and Confusion Matrix.

**Deep Learning**
- PyTorch and Torchvision.
- Convolutional Neural Network (CNN).
- Image classification: Car vs. Truck.
- Data augmentation.
- Training and validation.
- Model saving and image prediction.

**Main tools:** OpenCV, NumPy, Pandas, Scikit-learn, Matplotlib, PyTorch and Torchvision.
